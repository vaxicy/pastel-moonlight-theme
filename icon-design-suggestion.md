# Icon Design Suggestion

The bundled `icon.png` (256×256, generated by `scripts/generate_icon.py`) uses a **crescent moon on a pastel pink gradient** — dreamy and calm, never childish.

## Concept

A cream-white crescent moon floating on the theme's own pink tones, with a soft warm glow and a few minimal sparkle stars. It captures the theme's mood keywords directly: *pastel · soft · dreamy · clean*.

## Style Choices

- **Rounded square** (radius ≈ 22% of canvas) — modern flat iconography language.
- **Vertical gradient** `#F8E8EE` → `#F2BED1` — the theme's Panel → Accent tones, so the icon itself previews the palette.
- **Subtle stroke** `#EBB3C9` — defines the edge at large sizes, invisible at 16 px.
- **Crescent moon** `#FFFAF2` with Gaussian-blur glow — the focal point; warm white keeps contrast gentle.
- **Sparkle accents** in `#C2528B` (the theme's keyword rose) and warm white — ties the icon to the syntax palette without clutter.
- **No text** — stays crisp at 16 px.

## Sizes

VS Code requires `icon.png` ≥ 128 px; we ship 256×256. Up to 1024×1024 is accepted if more fidelity is wanted later.

## Alternative Sketches (future variants)

- Full moon with a slight pink blush shadow.
- Moon + tiny cloud (extra cozy, but busier at small sizes).
- Bento grid of the four palette tones for a designer-grid vibe.
